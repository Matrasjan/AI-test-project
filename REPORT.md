# Комментарий к тестовому заданию «ЭксТехСервис»

> Черновик. Перед отправкой проверьте формулировки и впишите своё время.

## С чего начинали
Первый шаг — разбор брифа: факты отделены от того, чего в нём нет. Факты: услуги, марки, адрес, график, пять преимуществ и три целевых действия (позвонить, оставить заявку, запросить расчёт). Нет: телефона, почты, MAX, цен и условий гарантии. Для этих данных сразу заложены заглушки в одном конфиге, чтобы ничего не выдумывать.

Три направления выбраны по тому, *как* сайт говорит с клиентом:
1. **«Тяжёлый металл»** — про мощь и надёжность. Тёмный фон, сигнальный жёлтый, огромная типографика. Подходит владельцу техники, который ищет «серьёзный сервис».
2. **«Чертёж»** — про экспертизу. Сайт показывает, что сервис понимает устройство машины: интерактивная схема узлов, спецификация услуг, бланк «наряд-заказа».
3. **«Маршрут к ремонту»** — про простоту обращения. Человечный тон и мастер из трёх вопросов прямо на первом экране, чтобы снизить барьер для частных лиц.

## Как шла работа
Идея и структура → сборка общего слоя (контакты, валидация формы, предзаполнение) → вёрстка трёх концепций с собственными SVG-иллюстрациями → автоматическая проверка в браузере (Playwright + Chrome) на 390 и 1440 px: горизонтальная прокрутка, ошибки JS, сценарий формы, интерактив → правки по скриншотам.

Что найдено и исправлено при проверке:
- на телефоне заголовок Concept 01 был шире экрана;
- ошибки валидации исчезали только после ухода из поля, из-за чего вёрстка «прыгала» и клик по следующему элементу промахивался;
- в Concept 03 в сетке bento оставалась пустая ячейка;
- заголовок Concept 01 на десктопе наезжал на иллюстрацию.

## Инструменты
Claude Code (агентная разработка в VS Code) и Playwright для автоматических скриншотов и проверок. Готовые шаблоны и UI-библиотеки не использовались: только чистый HTML/CSS/JS, все иллюстрации — собственные SVG. Шрифты — Google Fonts (OFL).

## Итог
Три концепции различаются не цветом, а устройством:

| | 01 «Тяжёлый металл» | 02 «Чертёж» | 03 «Маршрут» |
|---|---|---|---|
| Первый экран | Гигантский заголовок + силуэт машины | Лист чертежа со штампом | Вопрос + мастер из 3 шагов |
| Подача услуг | Нумерованный список | Схема машины + таблица-спецификация | Вкладки с карточками |
| Преимущества | «Стальные пластины» | «Технические условия ТУ-1…5» | Сетка bento |
| Заявка | Жёлтый блок с формой | Бланк наряд-заказа | Мастер → форма |
