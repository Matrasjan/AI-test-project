# ЭксТехСервис — три концепции лендинга

Тестовое задание «Веб-дизайн + AI-разработка». Три самостоятельных одностраничных прототипа для компании по ремонту и обслуживанию спецтехники в Сыктывкаре.

| Концепт | Папка | Идея |
|---|---|---|
| **Concept 01 · «Тяжёлый металл»** | [`concept-01/`](concept-01/index.html) | Тёмный индустриальный стиль, гигантская типографика, сигнальный жёлтый, бегущая лента услуг, услуги в виде нумерованного списка. |
| **Concept 02 · «Чертёж»** | [`concept-02/`](concept-02/index.html) | Инженерная калька и миллиметровка. Интерактивная схема экскаватора: нажимаете на узел, справа появляется описание услуги. Услуги поданы как спецификация, преимущества — как «технические условия», форма — как бланк «наряд-заказа». |
| **Concept 03 · «Маршрут к ремонту»** | [`concept-03/`](concept-03/index.html) | Тёплый, дружелюбный тон, мягкие формы. На первом экране мастер из трёх вопросов, ответы переносятся в форму. Преимущества собраны в сетку bento, услуги разложены по вкладкам, есть FAQ и условная схема проезда. |

Стартовая страница [`index.html`](index.html) ведёт на все три концепции.

---

## Как открыть проект

Проект — обычный статический HTML/CSS/JS **без сборки и зависимостей**.

### Вариант 1. Просто открыть файл
Откройте двойным щелчком файл `index.html` в корне проекта (Chrome, Safari, Firefox или Edge). Всё работает прямо из файловой системы.

### Вариант 2. Через локальный сервер (рекомендуется)
Так ссылки и шрифты работают так же, как на реальном хостинге.

```bash
# из корня проекта
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

или, если установлен Node.js:

```bash
npx serve .
```


> Для шрифтов нужен интернет (Google Fonts). Без сети страницы откроются с системными шрифтами — вёрстка не сломается.

## Структура

```
├── index.html            — стартовая страница со ссылками на 3 концепции
├── concept-01/           — «Тяжёлый металл»   (index.html + style.css)
├── concept-02/           — «Чертёж»           (index.html + style.css + скрипт схемы)
├── concept-03/           — «Маршрут к ремонту»(index.html + style.css + скрипт мастера/вкладок)
└── shared/
    ├── config.js         — контакты компании (телефон, почта, MAX) — ОДНО место для всех концепций
    └── app.js            — общее поведение: контакты, валидация формы, мобильное меню, предзаполнение
```


## Что работает

- Форма «Запросить предварительный расчёт» с валидацией: имя, телефон с маской +7, выбор техники или узла, описание, согласие на обработку данных. Ошибки выводятся под полями, после отправки показывается сообщение об успехе. **Форма демонстрационная: данные никуда не отправляются.**
- Кнопки «Расчёт» в карточках услуг сами подставляют нужную технику или узел в форму.
- Concept 02: кликабельные узлы на схеме (ДВС, гидронасос, распределитель, редуктор хода, техника целиком).
- Concept 03: мастер «Быстрый расчёт» из трёх шагов, вкладки услуг (переключаются и стрелками с клавиатуры), FAQ.
- Адрес открывается поиском в Яндекс Картах.
- Адаптивность проверена на ширине 390 и 1440 px: горизонтальной прокрутки нет. На телефоне внизу закреплена панель «Позвонить / Расчёт».
- Учтена настройка `prefers-reduced-motion`: если пользователь отключил анимации в системе, они не воспроизводятся.

## Соблюдение фактов брифа

Использованы только сведения из брифа: услуги, марки (Hitachi, JCB, Volvo, Hyundai — подписаны как «из брифа»), адрес, график и пять преимуществ. Цены, сроки и условия гарантии, годы работы, цифры, отзывы и сертификаты **не придуманы**. Где их не хватает, стоит пометка «уточнить у клиента». Описанный на сайтах порядок работы помечен как предложение для обсуждения. Написание названия «ЭксТехСервис» в подвале отмечено как требующее уточнения.
